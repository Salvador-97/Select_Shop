# Select Shop Inbound
Registro de producto y contenedores que llegan al almacén.

# Descripción
El software sirve para poder buscar la información de algun producto que se encuentre en el sistema del almacén para poder ingresar información acerca de su llegada en algún contenedor.

![Interfaz](/icons/Programa.PNG)

Como se puede ver en la primera sección se encuentra todo lo relacionado al producto, el cual sera buscado a traves del SKU. 

![Informacion](/icons/Informacion.PNG)

En esta sección si se desea modificar algún dato se puede hacer al oprimir el botón de "Editar" el cual habilitara todos los campos.

En la siguiente sección se agrega todo lo relacionado al contenedor, incluyendo el número total de tarimas que salieron con su respectivo resto. Para finalizar, se debe oprimir el botón de "Generar", con lo que se abrira una ventana para seleccionar un archivo en donde se va a escribir toda la información.
